# MyForecast

A weather forecasting and climate telemetry dashboard built with React,
TypeScript, and Vite.

Run `npm install` to install dependencies and `npm run dev` to start the
development server.

## Brand artwork

The MyForecast favicon and app icons adapt [Cloud Sun](https://fontawesome.com/icons/cloud-sun?f=classic&s=solid) by Fonticons, Inc., licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). MyForecast recolors and resizes the icon, adds a gradient background, and exports PNG versions for installation.
